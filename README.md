GeoMute

Context-Aware and Rule-Based Geofencing Framework for Audio Automation

GeoMute is an Android application that uses geofencing and location-based rules to automatically manage the device's audio mode when the user enters or exits predefined locations.
Features

📍 Create and manage geofenced locations
🔇 Automatically switch the phone to silent mode in designated quiet zones
🔔 Restore audio settings when leaving a geofenced area
🚨 Emergency contact handling
📱 Background geofencing support
🗺️ Google Maps integration
🔐 Location-based automation
