# GeoMute

## Context-Aware and Rule-Based Geofencing Framework for Audio Automation

GeoMute is an Android application that uses **geofencing and location-based rules** to automatically manage the device's audio mode when the user enters or exits predefined locations.

### Features

1. 📍 **Create and Manage Geofenced Locations**
   Define specific geographical areas and configure audio-related rules for each location.

2. 🔇 **Automatic Silent Mode**
   Automatically switches the device to silent mode when the user enters a designated quiet zone.

3. 🔔 **Automatic Audio Restoration**
   Restores the device's previous audio settings when the user leaves the designated geofenced area.

4. 🚨 **Emergency Contact Handling**
   Provides support for emergency contacts so important calls can be handled even when the device is in silent mode.

5. 📱 **Background Geofencing**
   Monitors geofenced locations in the background and applies configured rules without requiring the application to remain open.

6. 🗺️ **Google Maps Integration**
   Uses Google Maps to help users select, view, and manage geographical locations.

7. 🔐 **Location-Based Automation**
   Automatically applies predefined audio rules based on the user's geographical location.
